Política de Privacidad

1. Propósito de la recopilación y uso de datos

  • EmoPilot Log guarda el ID de CloudKit de cada usuario en su servidor para autenticación y seguimiento de uso.
  • EmoPilot Log detecta el país del usuario a partir de su dirección IP con fines estadísticos y de análisis. Sin embargo, la dirección IP no se almacena en la base de datos.
  • La información del usuario se guarda durante el período de prueba gratuita y se mantiene igual una vez iniciada la suscripción.
  • Esta información se conserva durante un año, incluso si el usuario no se suscribe o cancela la suscripción.

2. Retención de datos y prevención de abusos

  • Para prevenir abusos repetidos del período de prueba gratuita, EmoPilot Log conserva los ID de CloudKit durante un máximo de un año.
  • Estos datos se utilizan únicamente para determinar restricciones de uso y no se comparten ni utilizan con otros fines.

3. Manejo de datos al usar la función "Consejo"

  • Al usar la función "Consejo", el estado emocional seleccionado y el texto introducido se transmiten al servidor de OpenAI.
  • La entrada del usuario se procesa a través de la API de OpenAI y puede ser retenida temporalmente (hasta 30 días) en sus servidores para fines de monitoreo de abuso, de acuerdo con la política de uso de datos de OpenAI. Sin embargo, estos datos no se utilizan para entrenar ni mejorar modelos de IA.
  • Estos datos se usan únicamente para generar respuestas y no se almacenan en el servidor de EmoPilot ni se usan para ningún otro propósito.

4. Medidas de seguridad de los datos

  • Todos los registros se almacenan en el iCloud personal del usuario y siguen los protocolos de seguridad de Apple.
  • EmoPilot Log utiliza cifrado y controles de acceso para proteger los datos del usuario.

5. Cookies y registros

  • Este sitio web no utiliza cookies ni recopila información de los visitantes como direcciones IP o detalles del navegador.

6. Sin intercambio con terceros

  • EmoPilot no vende ni comparte información del usuario con terceros. Los datos se utilizan solo para proporcionar funciones de la app y análisis estadístico.

7. Derechos del usuario

  • EmoPilot no acepta solicitudes directas de eliminación de datos, pero aplica una política de eliminación automática tras el período establecido.

8. Consentimiento

  • Al tocar "Acepto" y seleccionar "Probar Gratis" o "Suscribirse", se considera que aceptas esta política de privacidad.

9. Cambios en la política

  • EmoPilot puede modificar esta política conforme a cambios legales o de servicio y notificará dichos cambios en esta página.
